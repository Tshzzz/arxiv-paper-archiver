# Attention Is All You Need Demo

这个目录保留了 demo 展示和对照阅读需要的关键产物：

- `Attention Is All You Need.pdf`
- `Attention Is All You Need.ocr.en.md`
- `Attention Is All You Need.ocr.rendered.en.md`
- `Attention Is All You Need.ocr_response.json`
- `Attention Is All You Need.translation.rendered.md`
- `figures/`

使用方式：

- 如果你想看 OCR 英文原文，打开 `Attention Is All You Need.ocr.en.md`
- 如果你想看英文带图版，打开 `Attention Is All You Need.ocr.rendered.en.md`
- 打开 `Attention Is All You Need.translation.rendered.md`
- 在 VS Code 或 Obsidian 中预览
- Markdown 会通过相对路径自动引用 `figures/` 中的图片

说明：

- 原始论文来自 arXiv `1706.03762v7`
- 中文稿基于 `GLM-OCR` 结果整理翻译
- 已额外保留英文 OCR 结果，方便和中文稿对照
